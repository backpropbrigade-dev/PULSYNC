# Impact case

## Challenge

PULSYNC addresses FEG Hackathon 2026 Challenge 01: Session Quality and
Session-to-Action Conversion.

## Prototype scope

The current demo presents the user-facing sports experience and supporting
portal surfaces needed to explore a session: sports feeds, event details, live
views, bet slip, wallet, bets, promotions, support, and operational pages.
Included mock data makes these flows reviewable without dependent services.

## Intended impact

The prototype provides a shared surface for evaluating how a user moves from
discovering an event to taking an action, while giving the team a concrete
frontend boundary for later backend and AI integration. Impact metrics and
validated outcomes should be added once the integrated services and evaluation
plan are available.
